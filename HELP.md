# Simple Line Editor - Help

## Commands

### 1. insert

Adds a new line at the specified line number.

Usage:
insert

The editor asks for the line number and text.

Example:
insert
Enter line number: 1
Enter text: Hello World

---

### 2. delete

Deletes a line from the document.

Usage:
delete

The editor asks for the line number.

Example:
delete
Enter line number: 1

---

### 3. display

Displays all lines in the document with line numbers.

Usage:
display

Example:

1. Hello World
2. I am learning C

---

### 4. save

Saves the current document to `document.txt`.

Usage:
save

Example:
Document saved successfully.

---

### 5. load

Loads the saved document from `document.txt`.

Usage:
load

Example:
Document loaded successfully.

---

### 6. exit

Closes the line editor.

Usage:
exit

Example:
Exiting editor...
